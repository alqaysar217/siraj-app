# **App Name**: منصة إتقان التعليمية

## Core Features:

- مساعد الدروس الذكي: استخدم أداة الذكاء الاصطناعي للحصول على تفسيرات إضافية وتلخيص الدروس بناءً على محتوى الفيديو.
- محرك حماية المشاهدة: برمجية تمنع تخطي أو تسريع الفيديو، مع احتساب وقت المشاهدة الفعلي لضمان إتمام الدرس.
- لوحة تحكم الزجاجية: واجهة مستخدم عصرية تعتمد على نمط Glassmorphism لعرض تقدم الطالب واشتراكاته.
- نظام التفعيل اليدوي: قاعدة بيانات لإدارة تفعيل حسابات الطلاب يدوياً من قبل الإدارة بعد التحقق من سندات الدفع.
- مكتبة الدروس التفاعلية: تصفح الدورات بتصميم Mobile-first مع عرض فيديوهات اليوتيوب المضمنة بشكل آمن ومحمي.
- سجل إنجازات الطلاب: تخزين البيانات السحابي لمتابعة التقدم الفعلي في الدروس ومنح الوصول للدروس المغلقة.

## Style Guidelines:

- Primary color: Electric Blue (#4d8aff) ليعكس طابع التقدم والتقنية الحديثة.
- Background color: Deep Slate Blue (#0e1117) بنسق داكن ليبرز تأثيرات الإضاءة الزجاجية.
- Accent color: Cyan Blue (#3fe8ff) لاستخدامه في أزرار التحكم وعناصر النيون.
- الخط المستخدم: 'Inter' بنمط Modern Sans-serif لضمان الوضوح التام في القراءة وتنسيق المحتوى العربي.
- أيقونات خطية ناعمة مع تأثيرات إضاءة نيون خفيفة تتماشى مع التصميم الزجاجي الحديث.
- تصميم متجاوب يعتمد مبدأ Mobile-first مع توزيع العناصر بأسلوب البطاقات الشفافة (Glass Cards).
- حركات انتقال سلسة للواجهات وظهور متدرج لعناصر النيون عند التفاعل.
